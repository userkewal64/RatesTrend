# 💱 RatesTrend

### 🌍 Explore. Compare. Convert.

RatesTrend is a simple currency platform that helps users explore global exchange rates, track currency movements, compare performance, and convert money through an intuitive interface.

## ✨ Features

| **Feature** | **Description** |
|---|---|
| 📈 **Currency Trends** | Explore exchange rate movements. |
| 📊 **Historical Charts** | View currency performance over time. |
| 🏆 **Top Gainers & Losers** | Discover currencies with notable changes. |
| ⚖️ **Currency Comparison** | Compare different currencies. |
| 💱 **Currency Converter** | Convert between supported currencies. |
| 🌐 **Global Currencies** | Explore currencies from around the world. |

## 🛠️ Built With

- 🌐 HTML5
- 🎨 CSS3
- ⚡ JavaScript
- 🔗 Exchange Rate APIs

## 🚀 Getting Started

1. Clone this repository.
2. Open the project folder.
3. Launch `index.html` in your browser.
